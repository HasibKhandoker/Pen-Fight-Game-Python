# ✏️ Pen Fight Game

A fun and interactive **Pen Fight Game** built with Python. Inspired by the classic pen-fighting game played on school desks, this project brings the nostalgic experience to your computer with a digital twist.

## 🎮 About the Game

Pen Fight Game is a simple and entertaining game where players compete using virtual pens. The goal is to defeat your opponent through strategic moves, timing, and skill.

This project is developed to explore Python game development, improve programming skills, and create an enjoyable gaming experience.

## ✨ Features

- 🎯 Interactive gameplay
- ✏️ Classic pen-fighting concept
- 🎨 Custom game graphics and interface
- 🕹️ Keyboard-based controls
- 🔊 Sound effects (if implemented)
- 🏆 Competitive gameplay
- 💻 Designed for desktop gaming

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Game Library:** Pygame (if used)
- **Development Environment:** Visual Studio Code
- **Version Control:** Git and GitHub

## 📥 Installation and Setup

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project Folder

```bash
cd pen-fight-game
```

### 3. Install Dependencies

If the game uses Pygame, install it with:

```bash
pip install pygame
```

### 4. Run the Game

```bash
python main.py
```

Replace `main.py` with your actual Python filename if it is different.

## 🎮 How to Play

1. Launch the game.
2. Follow the on-screen instructions.
3. Use the available controls to move or attack.
4. Try to defeat your opponent and win the match.
5. Enjoy the classic pen-fighting experience!

*Note: Actual controls and gameplay rules depend on the current implementation.*
